# **_Objetivo principal_**

Analizar el historial de ventas de PixelZone Perú para cuantificar cómo el precio (Total Price y Base Price) y el descuento aplicado (Price_Gap) afectan las unidades vendidas (Units Sold), y así dejar de fijar descuentos al azar durante campañas como Gamer Days o Black Friday.

---

## **_Objetivos específicos_**

1. Limpiar y explorar el dataset de ventas (tipos de variable, nulos y atípicos), calculando medidas de tendencia central y dispersión del precio y las unidades vendidas.  
2. Comparar, mediante gráficos, las unidades vendidas por tienda (Store ID) y según haya o no descuento (Price_Gap), para identificar qué tiendas y qué nivel de descuento rinden mejor.  
3. Determinar, mediante prueba de hipótesis e intervalos de confianza, si vender con descuento aumenta de forma significativa las unidades vendidas.  
4. Construir y evaluar un modelo de regresión lineal múltiple que estime las unidades vendidas a partir del precio base y del precio final.
